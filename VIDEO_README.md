## ⚙️ 4. Project Overview

The Railway Level Crossing Monitor is a digital hardware project developed using Verilog HDL. It monitors the expected sequence of railway crossing events and identifies invalid transitions or timeout conditions.

### Key Project Components

- Finite State Machine (FSM) control logic
- Sensor-event sequence monitoring
- Timeout and fault detection
- RTL simulation and waveform verification
- Yosys logic synthesis
- Static Timing Analysis (STA)
- Gate-Level Simulation (GLS)
- OpenLane physical design
- GDSII layout generation

### Design Flow

```text
RTL Design
    ↓
RTL Simulation
    ↓
Logic Synthesis
    ↓
Pre-layout STA
    ↓
Gate-Level Simulation
    ↓
Physical Design
    ↓
Post-layout STA
    ↓
GDSII Generation
```
